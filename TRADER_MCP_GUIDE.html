01获取代码

1
克隆仓库
bash 
git clone https://github.com/orangeZSCB/trader-mcp.git
cd trader-mcp

02安装依赖

2
安装项目依赖
bash 
pnpm install

这将在 node_modules/ 中安装所有工作区包的依赖。首次安装约需 2-5 分钟。

03配置系统

设置 OPENALICE_HOME

所有持久化数据（账户配置、交易记录、加密凭证）存储在 $OPENALICE_HOME 目录下。默认为 ~/.openalice。

bash 
# 使用默认路径
export OPENALICE_HOME=~/.openalice

# 或自定义路径
export OPENALICE_HOME=/data/trader-mcp

# 创建数据目录
mkdir -p $OPENALICE_HOME/data/config
⚠ 安全提示

sealing.key（AES-256 加密密钥）存储在 $OPENALICE_HOME/sealing.key。请确保该文件权限为 600，且定期备份。丢失此密钥将无法解密已保存的账户凭证。

环境变量一览

变量默认值说明
OPENALICE_HOME~/.openalice数据根目录
OPENALICE_TRADING_MCP_PORT47400MCP 服务端口
OPENALICE_UTA_PORT47333UTA 内部端口
OPENALICE_UTA_HEALTH_TIMEOUT_MS20000UTA 健康检查超时
OPENALICE_TRADING_AGENT_AUTHORopenclawcommit 作者标签

05新闻源配置

编辑 $OPENALICE_HOME/data/config/news.json 配置 RSS 新闻收集：

news.json 
{
  "enabled": true,
  "intervalMinutes": 10,
  "maxInMemory": 2000,
  "retentionDays": 7,
  "feeds": [
    {
      "name": "Federal Reserve",
      "url": "https://www.federalreserve.gov/feeds/press_all.xml",
      "source": "fed",
      "categories": ["macro"],
      "enabled": true
    }
  ]
}

新闻收集器在服务启动后自动运行，可通过 globRss、grepRss、readRss 工具查询。

06启动服务

开发模式

bash 
pnpm dev

此命令将依次启动：UTA 子进程 (端口 47333) → MCP 服务器 (端口 47400)。

生产构建

bash 
pnpm build
node dist/main.js

验证启动

bash 
curl http://127.0.0.1:47400/
# 应返回 JSON: {"service":"openalice-trading-mcp","uta":"http://127.0.0.1:47333",...}

07系统服务 (systemd)

7
创建 systemd 服务文件
/etc/systemd/system/trader-mcp.service 
[Unit]
Description=Trader MCP Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/trader-mcp
Environment=OPENALICE_HOME=/root/.openalice
ExecStart=/usr/bin/node dist/main.js
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
bash 
sudo systemctl daemon-reload
sudo systemctl enable --now trader-mcp
sudo systemctl status trader-mcp

08安装 OpenClaw

参考 OpenClaw 官方文档 安装。Linux (Debian) 快速安装：

bash 
curl -fsSL https://docs.openclaw.ai/install.sh | bash

09注册 MCP 服务器

bash 
openclaw mcp set trader-mcp \
  --transport streamable-http \
  --url http://127.0.0.1:47400/mcp

IDENTITY.md 
你是 **Trader MCP 交易助手**，一个专业的量化交易 AI。

## 核心职责
- 帮助用户管理交易账户和订单
- 执行 Trade-as-Git 工作流（stage → commit → push）
- 提供市场数据和交易分析
- 确保所有交易操作都经过用户明确授权

## 可用工具集（69 个工具）

### 账户管理
- `listAccounts` - 列出所有配置的交易账户
- `addAccount` - 添加新的交易账户
- `removeAccount` - 删除交易账户

### 交易操作
- `placeOrder` - 下单（stage）
- `modifyOrder` - 改单（stage）
- `cancelOrder` - 撤单（stage）
- `closePosition` - 平仓（stage）
- `tradingCommit` - 提交（commit）
- `tradingPush` - 推送（push，需要用户授权）
- `tradingReject` - 拒绝（reject）

### 量化分析
- `searchBars` - 查找 K 线数据源
- `calculateQuant` - 运行技术分析脚本

### 查询工具
- `listUTAs` / `getAccount` / `getPortfolio` / `getOrders`
- `getQuote` / `tradingStatus` / `tradingLog`

## 初始化行为
当用户第一次交互时：
1. 直接确认工具可用
2. 告诉用户 trader-mcp 工具已就绪
3. 询问需求

## 安全准则
- 所有交易操作遵循 Trade-as-Git 工作流
- push 操作必须获得用户明确授权
- 永远不要在聊天中暴露 API key

C故障排查

UTA 健康检查失败

检查 UTA 子进程日志（以 [uta] 前缀输出）。常见原因：端口 47333 被占用、账户配置无效、缺少 sealing.key。

新闻工具返回空数组

NewsCollector 需要时间拉取 feeds。服务启动后等待 10 分钟以上，或确认 news.json 中有 enabled: true 的 feeds。

"Already connected to a transport" 错误

Streamable HTTP transport 不支持多连接复用同一 session。请确保 OpenClaw 使用单一连接。

加密错误

确保 $OPENALICE_HOME/sealing.key 存在且可读。迁移数据目录时，务必同时复制此密钥文件。
