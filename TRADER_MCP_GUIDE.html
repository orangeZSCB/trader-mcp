1. 项目概述

Trader MCP 是一个基于 Model Context Protocol (MCP) 的智能交易系统，让 AI 助手 OpenClaw 能够安全、智能地执行交易操作。

💡 核心理念：所有交易操作都遵循 Git 工作流（Trade-as-Git），确保每一步都可追溯、可审计、可回滚。

适用场景

  • ✅ 虚拟盘策略测试和验证
  • ✅ 自动化网格交易
  • ✅ 智能订单管理
  • ✅ 多账户统一管理
  • ✅ 交易历史分析和复盘

2. 核心功能

🔒 Trade-as-Git 安全机制

所有交易操作都经过 stage → commit → push 流程，push 到交易所需要用户明确授权，杜绝误操作。

📊 19 个交易工具

涵盖查询、下单、改单、撤单、平仓等完整交易流程，满足各种交易需求。

🤖 AI 智能决策

OpenClaw 可以根据市场情况和策略自动执行交易，支持网格交易、RSI 过滤等策略。

📈 多交易所支持

支持 Binance、OKX、Bybit、Alpaca 等主流交易所，统一接口管理。

📝 完整审计日志

每笔交易都有完整的 commit 记录，可随时查看交易历史和决策过程。

⚡ 实时行情

实时获取市场价格、持仓、订单状态，确保决策基于最新数据。

3. 一键安装

✨ 最简单的方式：只需一条命令，OpenClaw 会自动完成所有安装和配置！

方式一：让 OpenClaw 自动安装（推荐）

在 OpenClaw 中发送以下消息：

# 复制这段话发给 OpenClaw 请读取这个文档并按照步骤安装 trader-mcp： https://raw.githubusercontent.com/orangeZSCB/trader-mcp/refs/heads/master/OPENCLAW_SETUP.md 安装完成后，验证： 1. MCP 服务器是否在运行 2. OpenClaw 是否能调用 trader-mcp 的工具 3. 尝试调用 listUTAs 工具

方式二：手动安装

1 克隆仓库
git clone https://github.com/orangeZSCB/trader-mcp.git cd trader-mcp
2 安装依赖
pnpm install
3 配置数据目录
export OPENALICE_HOME=/tmp/openclaw-test mkdir -p $OPENALICE_HOME/data/config # 创建账户配置 cat > $OPENALICE_HOME/data/config/accounts.json << 'EOF' [{ "id": "mock-test", "label": "Mock Test Account", "presetId": "mock-simulator", "enabled": true, "presetConfig": { "cash": 100000, "_instanceId": "openclaw-test-001" } }] EOF
4 启动 MCP 服务器
cd apps/mcp-server nohup node --conditions=openalice-source --import tsx src/main.ts > /tmp/trader-mcp.log 2>&1 &
5 配置 OpenClaw MCP
openclaw mcp set trader-mcp '{"transport":"streamable-http","url":"http://127.0.0.1:47400/mcp"}'
6 安装 Skill
mkdir -p ~/.openclaw/skills/openalice-trading cp skills/openalice-trading/SKILL.md ~/.openclaw/skills/openalice-trading/SKILL.md
7 验证安装
# 检查 MCP 服务器 curl http://127.0.0.1:47400/ # 检查 OpenClaw 配置 openclaw mcp list # 测试工具调用 openclaw agent --agent main -m "调用 listUTAs 工具" --local

8. 交易策略

网格交易策略

💡 策略原理：在价格区间内设置多个网格，当价格下跌到网格线时买入，上涨到网格线时卖出。利用震荡行情反复获利，胜率高（70-80%）。

策略参数

参数说明建议值
交易对交易标的AAPL / BTCUSDT
网格区间价格上下限根据历史波动设置
网格数量网格线数量10-20 格
每格金额每个网格的交易金额1000-5000 USD
RSI 过滤RSI 指标过滤< 35 买入，> 65 卖出

预期效果

  • ✅ 胜率：70-80%
  • ✅ 盈亏比：1:1.5（亏损 50，盈利 75）
  • ✅ 月化收益：5-15%（震荡行情）
⚠️ 风险提示：网格交易策略在单边行情（持续上涨或下跌）中可能亏损。建议设置止损，并密切监控策略执行情况。

9. 安全机制

Trade-as-Git 工作流

1 Stage（暂存）

所有交易操作先暂存到 staging area，不会立即执行。

2 Commit（提交）

生成 commit hash，记录交易决策和参数。

3 Push（推送）

需要用户明确授权后，才会推送到交易所执行。

✅ 安全保障：
  • 所有操作都有完整的 commit 记录
  • Push 操作需要用户明确授权
  • 可以随时查看和审计交易历史
  • 支持 reject 操作，取消未 push 的交易

数据加密

  • 敏感数据（API keys）使用 AES-256-GCM 加密存储
  • 加密密钥存储在 $OPENALICE_HOME/sealing.key
  • MCP 服务器默认只监听 127.0.0.1，不对外暴露

10. 故障排查

MCP 服务器无法启动

问题：端口 47400 被占用
# 检查端口占用 lsof -i :47400 # 杀掉占用进程 kill -9 <PID> # 或者使用其他端口 export OPENALICE_TRADING_MCP_PORT=47401

OpenClaw 无法连接 MCP

问题：OpenClaw 调用工具失败
# 检查 MCP 服务器是否运行 curl http://127.0.0.1:47400/ # 应该返回： # {"service":"openalice-trading-mcp","status":"running","version":"0.1.0"} # 检查 OpenClaw 配置 openclaw mcp list # 重新配置 openclaw mcp set trader-mcp '{"transport":"streamable-http","url":"http://127.0.0.1:47400/mcp"}'

Skill 未加载

问题：OpenClaw 不识别交易指令
# 检查 skill 文件 ls ~/.openclaw/skills/openalice-trading/SKILL.md # 检查 OpenClaw 是否识别 openclaw skills list | grep openalice-trading # 重新安装 skill mkdir -p ~/.openclaw/skills/openalice-trading cp skills/openalice-trading/SKILL.md ~/.openclaw/skills/openalice-trading/SKILL.md

交易工具调用失败

问题：工具返回错误
# 查看 MCP 服务器日志 tail -f /tmp/trader-mcp.log # 检查账户配置 cat $OPENALICE_HOME/data/config/accounts.json # 重启 MCP 服务器 pkill -f "mcp-server/src/main.ts" cd apps/mcp-server && nohup node --conditions=openalice-source --import tsx src/main.ts > /tmp/trader-mcp.log 2>&1 &
