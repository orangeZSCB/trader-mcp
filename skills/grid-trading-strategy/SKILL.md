# 网格交易策略

## 策略原理

在 BTC 价格区间内设置多个网格，当价格下跌到网格线时买入，上涨到网格线时卖出。
利用震荡行情反复获利，胜率高（70-80%）。

## 策略参数

```
交易对：BTCUSDT
网格区间：9000-11000 USD
网格数量：10 格（每格 200 USD）
每格金额：1000 USD（约 0.09-0.11 BTC）
RSI 过滤：RSI < 35 买入，RSI > 65 卖出
检查频率：每 5 分钟
止损：每笔订单 -5%
止盈：每笔订单 +2%
```

## 执行流程

1. 获取当前 BTC 价格和 RSI
2. 计算当前价格所在的网格位置
3. 如果 RSI < 35 且价格在网格下轨 → 买入
4. 如果 RSI > 65 且价格在网格上轨 → 卖出
5. 记录交易，更新网格状态

## 风险控制

- 单笔最大亏损：50 USD（5%）
- 单笔预期盈利：20-40 USD（2-4%）
- 最大持仓：5 个网格（5000 USD）
- 每日最大交易次数：20 次

## 预期效果

- 胜率：70-80%
- 盈亏比：1:1.5（亏损 50，盈利 75）
- 月化收益：5-15%（震荡行情）

## 使用方法

告诉 OpenClaw：
"启动网格交易策略"

OpenClaw 会：
1. 检查当前市场状态
2. 计算网格位置
3. 执行买卖操作
4. 报告交易结果
