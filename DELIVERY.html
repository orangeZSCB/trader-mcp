Core Philosophy

Trade-as-Git
每一笔交易都可追溯

所有交易操作都遵循 Git 工作流：stage → commit → push。 推送到交易所需要用户明确授权，杜绝误操作。每一步都可追溯、可审计、可回滚。

1
Stage
暂存交易意图
不影响真实账户
2
Commit
生成 commit hash
记录决策过程
3
Push
用户授权后执行
发送到交易所

Quick Start

一条命令
完成安装

只需将以下消息发送给 OpenClaw，它会自动完成所有安装和配置：

# 复制这段话发给 OpenClaw 请读取这个文档并按照步骤安装 trader-mcp： https://raw.githubusercontent.com/orangeZSCB/trader-mcp/refs/heads/master/OPENCLAW_SETUP.md 安装完成后，验证： 1. MCP 服务器是否在运行 2. OpenClaw 是否能调用 trader-mcp 的工具 3. 尝试调用 listUTAs 工具

或者手动安装：

# 克隆仓库 git clone https://github.com/orangeZSCB/trader-mcp.git cd trader-mcp # 安装依赖 pnpm install # 启动 MCP 服务器 cd apps/mcp-server pnpm dev
Architecture

基于 MCP 协议
安全、可扩展

Trader MCP 基于 Model Context Protocol (MCP) 构建，通过 Streamable HTTP 传输与 OpenClaw 通信。 所有敏感数据使用 AES-256-GCM 加密存储，密钥与数据分离。
